# Домашнее задание №6 по Go

**Группа:** BHEMBD-25  
**Студент:** Арсений Паниклов

Тема: «Тестирование в Go».

Проект продолжает сервисы `ledger` и `gateway` из предыдущего задания. В нём
добавлены таблично-ориентированные unit-тесты доменной модели и интеграционные
HTTP-тесты REST API.

## Что проверяется

- валидация транзакций и бюджетов;
- применение лимита бюджета и запрет сохранения отклонённой транзакции;
- очистка in-memory состояния методом `Reset()`;
- создание и получение бюджетов через HTTP;
- создание и получение транзакций через HTTP;
- ответы `400 Bad Request` и `409 Conflict`;
- формат ошибок и заголовок `Content-Type: application/json; charset=utf-8`.

Независимые unit-тесты выполняются параллельно, а последовательные HTTP-сценарии
объединены в читаемые подзадачи `t.Run`.

## Запуск тестов

Из корня репозитория:

```powershell
go test ./ledger/... ./gateway/...
```

Запуск с формированием отчёта о покрытии:

```powershell
go test '-coverprofile=cover.out' ./ledger/... ./gateway/...
go tool cover -func=cover.out
go tool cover -html=cover.out -o cover.html
```

Общее покрытие тестами — **86,4 %**. Пакет `ledger` покрыт на **94,2 %**,
пакет HTTP API — на **85,5 %**.

Файлы `cover.out` и `cover.html` не добавляются в репозиторий.

## Запуск Gateway

```powershell
go run ./gateway/cmd/gateway
```

REST API будет доступен по адресу `http://localhost:8080`.
